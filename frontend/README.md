# MovieMate 메인페이지

직접 준비한 영화 이미지와 제목을 넣어 사용하는 React 메인페이지입니다. 화이트·라이트 그레이와 넓은 여백을 중심으로 디자인했습니다. 영화 사진과 실제 영화 제목은 기본 데이터에 포함하지 않았습니다.

## VS Code에서 실행

1. Node.js **22.12 이상**을 설치합니다.
2. 압축을 풀고 `moviemate-main` 폴더를 VS Code로 엽니다.
3. VS Code에서 **터미널 → 새 터미널**을 열고 아래 명령을 순서대로 실행합니다.

```bash
npm install
npm run dev
```

4. 터미널에 표시되는 주소를 브라우저에서 엽니다. 기본 주소는 `http://127.0.0.1:5173`입니다.
5. 종료할 때는 터미널에서 `Ctrl + C`를 누릅니다.

`index.html` 파일을 직접 더블클릭하는 방식으로는 실행되지 않습니다. 항상 개발 서버를 실행해 주세요.

## 이미지와 제목 넣기

1. 메인페이지의 **영화 추가** 또는 빈 이미지 칸을 누릅니다.
2. 캡처하거나 내려받은 이미지를 선택하거나 업로드 영역에 끌어놓습니다.
3. 영화 제목을 입력하고 장르·개봉 연도·소개를 선택적으로 수정합니다.
4. **영화 추가**를 누르면 바로 메인페이지에 표시됩니다.
5. 상단 **영화 관리**에서 등록한 영화의 이미지·제목을 수정하거나 삭제할 수 있습니다.

| 설정 | 사용 방법 |
| --- | --- |
| 정사각형 1:1 | 영화 탐색 오른쪽의 `1:1` 버튼. 800 × 800px 이상 권장 |
| 영화 포스터 2:3 | `2:3` 버튼. 600 × 900px 이상 권장 |
| 전체 보기 | 기본값. 이미지 전체가 보이며 비율이 다르면 여백이 생깁니다 |
| 꽉 채우기 | 프레임을 채우며 가장자리가 일부 잘릴 수 있습니다 |

카드 비율은 목록 전체에 적용되고, 전체 보기/꽉 채우기는 영화마다 저장됩니다. 메인 상단의 대표 영화 영역은 가장 최근에 추가한 영화와 정사각형 프레임을 사용합니다. 이미지 비율이 달라도 늘리거나 찌그러뜨리지 않습니다. 제목은 이미지와 분리된 텍스트입니다.

지원 형식은 JPG, PNG, WebP, GIF이며 파일당 최대 8MB입니다. 등록한 사진은 다른 서버로 업로드되지 않습니다.

## 구현된 동작

- 데스크톱·태블릿·모바일 반응형 화면, 모바일 메뉴
- 이미지 업로드·미리보기·변경·삭제, 제목과 영화 정보 등록·수정·삭제
- 영화 제목·장르 검색, 장르 필터, 최근 추가순·내 평점순·제목순 정렬
- 1:1 / 2:3 카드 전환, 이미지 전체 보기 / 꽉 채우기
- 찜 추가·해제와 찜 목록
- 영화 상세, 1~5점 평점, 500자 이내 리뷰 작성·수정
- 나의 리뷰 미리보기, 평가한 영화 수, 찜한 영화 수
- 브라우저 저장 및 새로고침 후 복원
- 키보드로 조작 가능한 버튼, 모달 초점 관리, Escape 닫기

## 현재 구현 범위

이 프로젝트는 **프론트엔드 메인페이지**입니다. 로그인·회원가입, 실제 다른 회원의 게시글과 리뷰, 취향 유사도 계산, 개인화 추천, 회원·리뷰를 통합 관리하는 관리자 권한은 아직 연결하지 않았습니다. 관련 영역은 정직한 빈 상태와 준비 안내로 표시합니다.

현재의 **영화 관리**는 내 브라우저의 영화 목록 편집 기능이며 인증된 관리자 페이지는 아닙니다. 실제 서비스에서는 관리자 로그인과 서버의 권한 검사를 추가해야 합니다.

데이터는 **IndexedDB**에 저장됩니다. 같은 브라우저·같은 주소에서만 공유됩니다. 브라우저 사이트 데이터를 지우면 영화·평점·리뷰·찜도 사라집니다. 시크릿 창을 닫으면 기록이 사라질 수 있습니다. `localhost`와 `127.0.0.1`, 또는 다른 포트는 서로 다른 저장 공간입니다. 저장에 실패하면 화면에 오류를 표시하고 성공 처리하지 않습니다.

## 파일 구조

```text
moviemate-main/
  public/
    favicon.svg
    fonts/                 한국어 웹 폰트와 사용 허가문
    images/                필요하면 직접 정적 이미지를 추가할 폴더
  src/
    App.jsx                메인페이지, 영화 등록/상세, 영화 관리
    styles.css             공통 디자인과 반응형 스타일
    storage.js             IndexedDB 읽기·쓰기, 이미지 파일 검사
    components/
      Icon.jsx             SVG 아이콘
      Modal.jsx            공통 대화상자
    main.jsx               React 시작점
  index.html
  package.json
  package-lock.json
```

## STS / Spring Boot / Oracle 연결 위치

React는 Spring Boot의 HTTP API를 호출하고, Spring Boot가 Oracle Database에 접근하는 구조로 연결하면 됩니다. Oracle SQL Developer는 데이터 조회·관리를 위한 도구입니다. 데이터베이스 계정이나 비밀번호를 React 코드에 넣지 않습니다.

아래 경로는 **후속 개발을 위한 제안**이며 현재 작동하는 API는 아닙니다.

| 기능 | API 예시 |
| --- | --- |
| 회원가입 / 로그인 | `POST /api/auth/signup`, `POST /api/auth/login` |
| 영화 조회 / 등록 | `GET /api/movies`, `POST /api/admin/movies` |
| 영화 수정 / 삭제 | `PATCH /api/admin/movies/{id}`, `DELETE /api/admin/movies/{id}` |
| 찜 | `PUT /api/me/watchlist/{movieId}`, `DELETE /api/me/watchlist/{movieId}` |
| 평점·리뷰 | `PUT /api/me/reviews/{movieId}` |
| 취향 매칭 / 추천 | `GET /api/me/matches`, `GET /api/me/recommendations` |
| 커뮤니티 | `GET /api/posts`, `POST /api/posts` |

`src/storage.js`의 저장 방식을 API 서비스 모듈로 교체한 뒤 `App.jsx`의 영화 조회·저장·찜·평가 처리 함수에 연결하세요. 실제 API에서는 상태 전체를 덮어쓰는 대신 기능별 요청을 사용하는 편이 좋습니다. 이미지 파일은 `multipart/form-data` 등으로 별도 업로드하고, 응답받은 이미지 URL을 영화 정보에 저장할 수 있습니다.

## 배포용 빌드

```bash
npm run build
npm run preview
```

빌드 결과는 `dist` 폴더에 만들어집니다. 실제 배포나 서버 연결은 포함되어 있지 않습니다.

## 디자인 편집

- 색상: `src/styles.css` 맨 위 `:root` 변수
- 메인 문구·섹션: `src/App.jsx`
- 카드 비율: `.artwork.square`, `.artwork.poster`
- 카드 개수·반응형: `.movie-grid`와 하단 미디어 쿼리
- 사진의 기본 맞춤: `Artwork` 컴포넌트의 `objectFit`

사진/제목을 처음부터 코드에 넣고 싶다면 `public/images`에 파일을 넣고 초기 데이터 로딩을 별도로 구성할 수 있습니다. 현재 기본 사용법은 화면의 업로드 버튼입니다. 폰트는 Noto Sans CJK KR에서 웹용으로 서브셋한 파일이며 라이선스는 `public/fonts/LICENSE.txt`에 포함했습니다.
